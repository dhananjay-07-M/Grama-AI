
# GramAI - Rural Empowerment & Local Access 🌿🚜

**GramAI** is a cutting-edge intelligent virtual assistant designed specifically for rural India. It leverages advanced Artificial Intelligence to bridge the digital divide, providing farmers with real-time agricultural insights, market data, and expert advisory services in their local languages.

![GramAI Banner](https://images.unsplash.com/photo-1625246333195-5519a646d9aa?auto=format&fit=crop&q=80&w=2000)

## 🚀 Mission
To empower every farmer with accessible technology, increasing crop yields, ensuring fair market prices, and providing financial security through a simple, voice-first interface.

---

## ✨ Key Features

### 🤖 AI Voice Assistant (IVR & Chat)
- **Voice-First Interface:** Farmers can "call" the assistant and interact using natural voice commands in local languages (Hindi, Kannada, English).
- **Multimodal Support:** Supports text and voice interactions for high accessibility.

### 🩺 Crop Doctor (AI Diagnosis)
- **Instant Diagnosis:** Simply take a photo of a sick plant.
- **Gemini Vision Analysis:** The AI identifies diseases, pests, or nutrient deficiencies and suggests specific treatments and medicines.

### 📈 Market Mandi (Price Intelligence)
- **Real-Time Prices:** Live commodity prices from nearby mandis.
- **Price Prediction:** AI-generated 7-day price forecast graphs to help farmers decide when to sell.
- **Nearby Markets:** GPS-based locator for agricultural markets and dealers.

### 🌦️ Precision Weather
- **Hyper-Local Forecasts:** Accurate weather data based on GPS coordinates.
- **Offline Alerts:** Simulates SMS alerts for areas with low internet connectivity.

### 🏛️ Government Schemes
- **Smart Discovery:** Finds active Central and State government schemes.
- **Eligibility Checker:** AI analyzes the farmer's profile to determine eligibility for subsidies and benefits.

### 💼 Agri Jobs
- **Local Employment:** Connects farm laborers with land owners.
- **Job Finder:** Search for harvesting, tractor driving, and nursery jobs nearby.

### 🛡️ Admin Command Center
- **Farmer Management:** Verify and manage registered users.
- **Broadcast System:** Send emergency alerts (e.g., heavy rain, pest outbreaks) to all farmers instantly.
- **Market Control:** Update daily mandi rates.

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript, Vite
- **Styling:** Tailwind CSS
- **AI Engine:** Google Gemini API (`@google/genai`)
  - *Gemini 2.5 Flash* (Speed & Vision)
  - *Gemini 3 Pro* (Complex Reasoning)
  - *Gemini TTS* (Text-to-Speech for Voice Mode)
- **Icons:** Lucide React
- **Maps & Location:** Browser Geolocation API & Google Maps Grounding

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- Google Gemini API Key

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/gramai.git
   cd gramai
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment**
   Create a `.env` file in the root directory and add your API key:
   ```env
   API_KEY=your_google_gemini_api_key_here
   ```

4. **Run the Application**
   ```bash
   npm start
   ```
